# ❌ Error 404 - FCM API не включен

## Вы ОБЯЗАТЕЛЬНО должны включить Cloud Messaging API:

### Шаг 1: Откройте эту ссылку:
```
https://console.cloud.google.com/apis/library/fcm.googleapis.com?project=akadiledu
```

### Шаг 2: Нажмите "ENABLE" (Включить)

### Шаг 3: Подождите 1 минуту

### Шаг 4: Проверьте что API включен:
```
https://console.cloud.google.com/apis/dashboard?project=akadiledu
```

В списке должно быть:
```
✅ Cloud Messaging API - Enabled
```

## Если API включен но ошибка остается:

### Проблема: Нет FCM токенов в базе

1. Откройте Firebase Console:
```
https://console.firebase.google.com/project/akadiledu/database/akadiledu-default-rtdb/data
```

2. Перейдите в `users` → найдите своего пользователя

3. Проверьте есть ли `fcmToken`

4. Если токена нет:
   - Откройте сайт https://akadiledu.web.app
   - Войдите в аккаунт
   - В консоли браузера (F12) выполните:
   ```javascript
   localStorage.removeItem('fcm_permission_requested');
   location.reload();
   ```
   - Разрешите уведомления когда спросит

5. Токен должен появиться в базе
