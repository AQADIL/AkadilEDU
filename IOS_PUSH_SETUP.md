# 📱 Push Notifications на iOS (iPhone/iPad)

## ⚠️ ВАЖНО: Ограничения iOS

### iOS Safari не поддерживает Web Push Notifications!

**До iOS 16.4**, Safari вообще не поддерживал push-уведомления для веб-приложений.

**С iOS 16.4+** появилась поддержка, НО с ограничениями:
- ✅ Работает ТОЛЬКО для PWA, добавленных на Home Screen
- ❌ НЕ работает в обычном Safari браузере
- ❌ НЕ работает в режиме инкогнито
- ✅ Требуется iOS 16.4 или новее

---

## ✅ Как включить push на iPhone

### Шаг 1: Проверьте версию iOS
```
Настройки → Основные → Об этом устройстве → Версия ПО
Нужна: iOS 16.4 или новее
```

### Шаг 2: Добавьте сайт на Home Screen

1. Откройте сайт в **Safari** (не Chrome!):
   ```
   https://akadiledu.web.app
   ```

2. Нажмите кнопку **"Поделиться"** (📤 внизу экрана)

3. Выберите **"Добавить на экран «Домой»"** (Add to Home Screen)

4. Нажмите **"Добавить"**

### Шаг 3: Откройте приложение с Home Screen

1. **НЕ ОТКРЫВАЙТЕ через Safari!**
2. Найдите иконку **AkadilEDU** на главном экране
3. Откройте приложение **через иконку**

### Шаг 4: Войдите в аккаунт

1. Войдите через Google или Email
2. Приложение запросит разрешение на уведомления
3. Нажмите **"Разрешить"**

### Шаг 5: Проверьте разрешения

```
Настройки → AkadilEDU → Уведомления
Убедитесь что уведомления включены
```

## 🔍 Диагностика проблем на iOS

### Проблема: "Не запрашивает разрешение"

**Решение:**
```
1. Удалите приложение с Home Screen
2. Очистите историю Safari:
   Настройки → Safari → Очистить историю и данные
3. Добавьте приложение заново
4. Откройте ЧЕРЕЗ ИКОНКУ (не через Safari!)
```

### Проблема: "Разрешил, но уведомления не приходят"

**Проверьте:**
```
1. iOS версия 16.4+?
2. Открыли через иконку на Home Screen?
3. Не в режиме инкогнито?
4. В настройках iOS уведомления включены?
```

### Проблема: "В Safari работает, на Home Screen нет"

**Это нормально!** В Safari push не работает на iOS.
Работает ТОЛЬКО через PWA (иконка на Home Screen).

## 📊 Совместимость

| Платформа | Браузер | Поддержка |
|-----------|---------|-----------|
| **Android** | Chrome | ✅ Полная |
| **Android** | Firefox | ✅ Полная |
| **Android** | Edge | ✅ Полная |
| **iOS 16.4+** | Safari PWA | ✅ Только PWA |
| **iOS** | Safari браузер | ❌ Нет |
| **iOS** | Chrome | ❌ Нет* |
| **iOS** | Firefox | ❌ Нет* |
| **Desktop** | Chrome | ✅ Полная |
| **Desktop** | Firefox | ✅ Полная |
| **Desktop** | Edge | ✅ Полная |
| **Desktop** | Safari | ✅ macOS 13+ |

\* На iOS все браузеры используют WebKit, поэтому ограничения Safari применяются ко всем.

## 🎯 Рекомендации

### Для пользователей iOS:
1. Используйте Safari (не Chrome)
2. Добавьте на Home Screen
3. Открывайте через иконку
4. Обновите iOS до 16.4+

### Для пользователей Android:
Всё работает из коробки в любом браузере! 🎉

### Для Desktop:
Всё работает во всех современных браузерах! 🎉

## 📝 Тест на iOS

### Проверочный чек-лист:
- [ ] iOS версия 16.4 или новее
- [ ] Сайт добавлен на Home Screen через Safari
- [ ] Открыт через иконку (не через Safari)
- [ ] Выполнен вход в аккаунт
- [ ] Разрешение на уведомления предоставлено
- [ ] В Настройках → AkadilEDU уведомления включены
- [ ] FCM токен сохранен (проверить в Firebase Console)

Если все пункты ✅ - push должны работать!

---

## 🆘 Если ничего не помогло

### На iOS push может не работать если:
1. Используете VPN/AdBlock - попробуйте отключить
2. Режим "Не беспокоить" включен
3. Ограничения корпоративного профиля
4. Бета-версия iOS с багами

### Альтернатива для iOS:
Используйте desktop версию на компьютере или Android устройство для гарантированной работы push-уведомлений.

---

**Итог:** Push на iOS работают, но с ограничениями Apple. Лучший опыт - на Android и Desktop! 🚀
