# 🔒 СИСТЕМА БЕЗОПАСНОСТИ И IP-ТРЕКИНГА

## 🎯 Что Реализовано

Полная система защиты от мультиаккаунта и отслеживания подозрительной активности!

---

## 📊 Возможности

### 1. ✅ IP-Трекинг
- Автоматическое определение IP адреса при каждом логине
- История всех IP адресов пользователя
- Геолокация по IP

### 2. ✅ Детекция Устройств
- Определение браузера, ОС, типа устройства
- Уникальный отпечаток устройства (fingerprint)
- История всех использованных устройств

### 3. ✅ Анализ Подозрительной Активности

**Система автоматически обнаруживает:**

#### 🚨 Критично (Critical):
- **Одновременные сессии** с разных IP адресов
  - Несколько людей используют один аккаунт ПРЯМО СЕЙЧАС

#### ⚠️ Высокий риск (High):
- **Множественные IP адреса** (>3 за 24 часа)
  - Аккаунт используется из разных мест
- **Множественные устройства** (>5 за 24 часа)
  - Слишком много устройств для одного человека

#### 🟡 Средний риск (Medium):
- **Быстрая смена IP** (в течение часа)
  - Переезд между локациями за короткое время
  - Может быть VPN

### 4. ✅ Система Оповещений

**Для Пользователя:**
- Уведомления о входе с нового устройства/IP
- Предупреждения о подозрительной активности
- Рекомендации по безопасности

**Для Админа:**
- Специальная панель `/admin/security`
- Все алерты в реальном времени
- Информация о каждой сессии
- Кнопка "Решено" для обработанных алертов

## 🚀 Как Это Работает

### При Логине:

```javascript
1. Пользователь вводит email и пароль
   ↓
2. Firebase Auth проверяет credentials
   ↓
3. ✅ Успешный вход
   ↓
4. 📊 Сбор информации:
   - Получение IP адреса (через API)
   - Определение устройства (браузер, ОС, fingerprint)
   - Создание сессии
   ↓
5. 💾 Сохранение в Realtime DB:
   - Добавление сессии
   - Обновление IP истории
   - Обновление lastLogin
   ↓
6. 🔍 Анализ безопасности:
   - Получение всех сессий пользователя
   - Проверка на подозрительную активность
   - Расчёт уровня риска
   ↓
7. 🚨 Если подозрительно:
   - Создание алерта для пользователя
   - Создание алерта для админа
   - Обновление securityStatus
   ↓
8. ✅ Логин завершён
```

## 🛡️ Типы Детекции

### 1. Multiple IPs (Множественные IP)
**Триггер:** >3 разных IP за 24 часа

**Пример:**
```
Утро:  192.168.1.1  (Дом)
День:  10.0.0.1     (Работа)
Вечер: 172.16.0.1   (Кафе)
Ночь:  93.184.1.1   (Друг?)  ← ПОДОЗРИТЕЛЬНО!
```

**Уровень:** High

---

### 2. Multiple Devices (Множественные устройства)
**Триггер:** >5 разных устройств за 24 часа

**Пример:**
```
Device 1: Chrome/Windows/Desktop
Device 2: Safari/iOS/Mobile
Device 3: Firefox/macOS/Desktop
Device 4: Chrome/Android/Mobile
Device 5: Edge/Windows/Desktop
Device 6: Opera/Linux/Desktop  ← ПОДОЗРИТЕЛЬНО!
```

**Уровень:** High

---

### 3. Rapid IP Change (Быстрая смена IP)
**Триггер:** Смена IP менее чем за час

**Пример:**
```
16:00 → Login from 192.168.1.1 (Москва)
16:30 → Login from 93.184.1.1 (Санкт-Петербург)
Разница: 30 минут ← ПОДОЗРИТЕЛЬНО!
```

**Уровень:** Medium

---

### 4. Simultaneous Sessions (Одновременные сессии)
**Триггер:** Активные сессии с разных IP в течение 5 минут

**Пример:**
```
16:00 → Active from 192.168.1.1
16:02 → Active from 10.0.0.1
16:03 → Active from 172.16.0.1

Одновременно 3 IP! ← КРИТИЧНО!
```

**Уровень:** Critical

## 🔧 API Функции

### Device Info Utils (`src/utils/deviceInfo.js`)

```javascript
// Получить информацию об устройстве
getDeviceInfo()
// Returns: { browser, os, deviceType, fingerprint, userAgent, ... }

// Получить IP адрес
await getUserIP()
// Returns: { ip, timestamp }

// Получить геолокацию по IP
await getIPLocation(ip)
// Returns: { country, city, timezone, coordinates }

// Создать полный профиль сессии
await createSessionProfile()
// Returns: { device, ip, timestamp, sessionId }

// Проверка подозрительной активности
detectSuspiciousActivity(userSessions, currentSession)
// Returns: { suspicious: bool, flags: [], riskLevel: string }
```

```javascript
// Логирование сессии
```

## 🔒 Безопасность

### IP Detection APIs:

Используются бесплатные публичные API:
- `api.ipify.org` - определение IP
- `api.ip.sb` - определение IP (fallback)
- `ipapi.co` - геолокация

**Privacy:**
- IP адреса хранятся зашифрованно в Firebase
- Доступ только для админов
- Пользователи видят только свои данные
