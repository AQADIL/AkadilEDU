# ❌ ПРОБЛЕМА: Error 404 при отправке Push

## Причина:
**Firebase Cloud Messaging API не включен в вашем проекте**

## ✅ РЕШЕНИЕ (1 минута):

### Откройте ЭТУ ссылку:
```
https://console.cloud.google.com/apis/library/fcm.googleapis.com?project=akadiledu
```

### Нажмите синюю кнопку "ENABLE"

### Подождите 30 секунд

### Готово! Push заработают

---

## Проверка:

После включения API:
1. Обновите админ панель
2. Отправьте push
3. Должно быть: ✅ Отправлено X из Y пользователей

Если ошибка 404 исчезла - всё работает!
