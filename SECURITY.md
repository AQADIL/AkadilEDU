# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to **Akadil Alish**, the project
owner. When available, use **Security → Report a vulnerability** on GitHub.
Do not disclose vulnerabilities in public issues or pull requests.

Include the affected feature or version, steps to reproduce the issue and its
potential impact. Remove passwords, access tokens and personal information from
screenshots and other supporting material. Never include student records or
database exports.

## Responsible testing

Test only accounts and data you are authorized to access. Avoid actions that
interrupt the service or expose other users' information. Coordinate public
disclosure with the project owner so that a fix can be prepared.

## Scope

Security reports should concern the current version of AkadilEdu on `main`.
For ordinary bugs and feature requests, use GitHub Issues.
